超分辨 v1.2
============================================================
视频超分（放大）+ 补帧（插帧）+ 图片超分
全中文 · 命令行界面 · 开源引擎 · 可商用
============================================================

一、图形版界面
------------------------------------------------------------
最上面第一个框是「处理对象」，先选这个：

  视频（超分 + 补帧）  →  下面出现：处理模式、快速预设、基础/高级参数、
                          补帧模型、输出分辨率、调色 LUT
  图片（只超分，不补帧）→  下面只剩：超分模型、放大倍数

选哪个，下面就只显示哪一套参数，不会混在一起。

二、怎么用（视频，命令行版）
------------------------------------------------------------
1. 双击「超分辨.exe」，把视频文件拖进窗口（或输入完整路径）；
2. 首次会问：是否修改参数？直接回车走默认；
3. 问"开始处理？"回车即可；
4. 处理完在「输出\」文件夹里拿成片，文件名带 _up2x_48fps 这类后缀。

也可以把视频文件直接拖到「超分辨.exe」图标上运行。

三、怎么用（图片）
------------------------------------------------------------
图片走的是同一条路，程序会自己认出来。

1. 把图片拖进窗口，或者把整个文件夹拖进来（批量）；
2. 只问两项：超分模型、放大倍数（图片不需要补帧）；
3. 处理完在「输出\」里，文件名是 原名_up2x.png 这样。

支持的格式：
  png / jpg / jpeg / webp / bmp / tif / tiff

批量说明：
  拖一个文件夹进去，会把这个文件夹里所有图片都处理一遍，
  输出到「输出\」，不覆盖原图。

图片模式的建议：
  · 写实照片、模型渲染图 → realesrgan-x4plus（只支持 ×4）
  · AI 生成的图、动画截图 → realesr-animevideov3（×2/3/4 都行，快）
  · 人像怕被重画脸 → realcugan-pro（保守，×2/3）
  · 输出一律存成 png，不损失再压缩

四、默认参数（改过一次会记住）
------------------------------------------------------------
  超分模型：realesr-animevideov3   ×2
  补帧模型：rife-v4.6              ×2
  输出分辨率：1080p（用超采样缩小，最干净）
  画质 CRF：16
  每段处理：10 秒（控制磁盘占用）
  GPU 编号：0

五、参数怎么选
------------------------------------------------------------
【超分模型】
  realesr-animevideov3   视频向，快，适合 AI 生成的片子（推荐）
  realesrgan-x4plus      写实照片向，慢，细节多但可能"过度锐化"
  realesrgan-x4plus-anime 动漫向

【超分倍数】
  2 = 快，够用（480p → 960p 再缩到 1080p）
  3 / 4 = 更干净，但慢一倍以上

【补帧模型】
  rife-v4.6   通用，质量最好（推荐）
  rife-anime  动漫向
  rife-HD     高清向

【补帧倍数】
  2 = 24fps → 48fps（推荐，保留电影感）
  3 = 24fps → 72fps（更顺滑，但会"像游戏"）
  4 = 24fps → 96fps（不建议）

【输出分辨率】
  1080 / 720 / 原始（只按倍数放大，不缩放）

六、注意（很重要）
------------------------------------------------------------
1. 只处理画面，音轨会自动从原片接回来；如果原片没声音，成片也没有；
2. 中间文件在「work\」里，处理完会问要不要删；不删的话很占地方（几十 GB 很常见）；
3. 失败时看「日志\」里的 .log，里面有每条命令的原始输出；
4. 补帧会让 AI 生成画面的瑕疵更明显，别贪帧（24→48 足够）；
5. 字幕、文字画面别先烧进去——**先超分补帧，最后再叠字幕**，否则字会糊；
6. 图片模式不走调色 LUT、不加颗粒（要调色请处理完自己叠）。

七、目录说明
------------------------------------------------------------
  超分辨.exe      主程序（命令行）
  超分辨_图形版.exe  图形界面
  bin\            三个引擎 + 模型（别删、别改名）
    realesrgan-ncnn-vulkan.exe   超分引擎（BSD-3）
    rife-ncnn-vulkan.exe         补帧引擎（MIT）
    ffmpeg.exe                   拆帧/合帧/接音轨
    models\                      超分模型
    rife-*\                      补帧模型
  work\           中间文件
  输出\           成片与超分后的图片
  日志\           运行日志
  config.json     记住的参数（删掉就恢复默认）

九、调色 LUT
------------------------------------------------------------
  lut\ 目录里三个 LUT，编码时直接套：
    heavy_industrial.cube   灰黑重工业（默认）
    cold_archive.cube       冷蓝档案
    warm_industrial.cube    暖橙工业

  参数菜单里的两项：
    调色 LUT（0 无 / 1 灰黑重工业 / 2 冷蓝档案 / 3 暖橙工业）
    胶片颗粒（0 关 / 1 轻 / 2 中）

  效果方向：
    · 对比 +12%，饱和 -20%
    · 高光滚降、暗部抬升一点（不死黑）
    · 暗部偏青、整体偏冷
    · 叠一层 3% 胶片颗粒，压掉"塑料感"
